# Myflo — All Screen Shorts (short-form scripts, one per screen)

**Format:** vertical 9:16 or square 1:1 short-form (TikTok/Reels style) ~6–12s per screen.
**Use:** paste any short into Arena AI video generation as a video prompt, or film manually following the shot notes.
**Rule:** no invented stats — every frame shows real app states ("Running", "Real data pending"), never fake numbers.
