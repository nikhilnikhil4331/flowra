## Description (paste)
Myflo is a cycle-tracking PWA. For Toggle Wars Track 01 ("Test Something Real") it
runs a live Flagsmith Experimentation A/B test in production: new anonymous visitors
are split 50/50 between a neutral splash CTA ("Get Started") and a warm one
("Start my cycle 🌸"). Completing the goals-setup step fires the conversion metric
`experiment_conversion_metric`; every funnel event is mirrored to a PII-free Supabase
audit table. No simulated traffic, no fabricated dashboards — the win probability is
whatever real users decide.
